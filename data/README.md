# Données du projet

| Dossier | Contenu | Mise à jour |
| --- | --- | --- |
| [`objectif3-sinistres/`](objectif3-sinistres/) | Sinistres auto et moto en Europe, nettoyés, pour prédire le coût d'un sinistre | Automatique |

Les données de l'objectif 3 sont produites par le dépôt [assuria-donnees](https://github.com/adam-hassen/assuria-donnees)
(collecte + nettoyage chaque semaine). Elles sont recopiées ici automatiquement toutes les heures
par le workflow `.github/workflows/sync-donnees-objectif3.yml`. Ne pas les modifier à la main.

Description complète du jeu de données : [`objectif3-sinistres/README.md`](objectif3-sinistres/README.md).
